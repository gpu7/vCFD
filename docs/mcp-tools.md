# MCP Tools

| Tool | Description |
|------|-------------|
| `list_templates` | Available case templates |
| `list_cases` | Workspace cases + status |
| `create_case` | Create from template |
| `describe_case` | Overview of one case |
| `delete_case` | Delete (confirm) |
| `clean_case` | Remove times/VTK (confirm) |
| `set_pipe_parameters` | Geometry/fluid/mesh for pipe |
| `generate_mesh` | blockMesh |
| `check_mesh` | checkMesh summary |
| `start_solver` | Background solver → job_id |
| `get_job_status` | Poll job |
| `get_logs` | Log tail |
| `stop_job` | Stop running job |
| `summarize_results` | Spoken results summary |
| `compare_to_analytical` | Hagen–Poiseuille comparison |
| `export_for_paraview` | foamToVTK + zip |
